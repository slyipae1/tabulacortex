## Available Tools and Parameters:

1. **delete_table_tool**
   - `table_identifier` (str): table_id or table_name to delete

2. **create_table_tool**
   - `table_entry` (Dict): **COMPLETE** table entry with table_id, table_name, columns_mapping

3. **merge_table_tool**
   - `table_identifier1` (str): First table to merge
   - `table_identifier2` (str): Second table to merge  
   - `table_identifier_new` (str): Name for the new merged table

4. **delete_column_tool**
   - `table_identifier` (str): table_id or table_name
   - `column_identifier` (str): column_id or column_name to delete

5. **create_column_tool**
   - `table_identifier` (str): table_id or table_name
   - `column_entry` (Dict): **COMPLETE** column entry with all required fields

6. **merge_column_tool**
   - `table_identifier` (str): table_id or table_name
   - `column_identifier1` (str): First column to merge
   - `column_identifier2` (str): Second column to merge
   - `column_identifier_new` (str): Name for the new merged column
   - `transform_for_DB1` (str): ORIGINAL: the transform_for_DB for First column in the merged column, default is ORIGINAL
   - `transform_for_DB2` (str): ORIGINAL: the transform_for_DB for Second column in the merged column, default is ORIGINAL

7. **add_foreign_keys_tool**
   - `new_foreign_keys` (List[List[str]]): List of foreign key relationships to add

8. **update_whole_foreign_keys_tool**
   - `new_whole_foreign_keys` (List[List[str]]): **COMPLETE** replacement foreign keys

9. **update_db_name_tool**
   - `new_db_name` (str): New database name

10. **update_table_name_tool**
   - `table_identifier` (str): table_id or table_name to update
   - `new_table_name` (str): New table name

11. **update_column_tool**
   - `table_identifier` (str): table_id or table_name
   - `column_identifier` (str): column_id or column_name to update
   - `field_name` (str): the field to be updated, can ONLY be one of ["column_name", "col_constraints", "datatype", "original_column_xlsx"]
   - `new_value` (str | List[str] | List[Dict]): the new value to be replaced
